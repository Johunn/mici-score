MICI Score : dossier d'installation (PWA) pour GitHub Pages

Contenu : index.html (l'appli), manifest.webmanifest, sw.js (hors ligne), dossier icons.
Les fichiers doivent être directement à la racine du dépôt GitHub (pas dans un sous-dossier).

Étapes (depuis un ordinateur) :
1. Décompresser le zip.
2. Sur github.com : « + » > New repository. Nom : mici-score. Public. Créer.
3. « uploading an existing file » : glisser index.html, manifest.webmanifest, sw.js, LISEZ-MOI.txt et le dossier icons. Commit changes.
4. Settings > Pages > Build and deployment > Source : Deploy from a branch > Branch : main, dossier /(root) > Save.
5. Attendre 1 à 2 minutes. L'adresse apparaît en haut de la page Pages : https://TON-PSEUDO.github.io/mici-score/
6. Ouvrir cette adresse dans Chrome sur le téléphone > trois points > Installer l'application.

Sauvegarde des données : une autre adresse = un autre stockage. Avant de changer, Profil > « Copier la sauvegarde » dans l'ancienne appli, puis Profil > « Restaurer depuis une sauvegarde » dans la nouvelle.
Mises à jour : remplacer index.html sur GitHub (Add file > Upload files, même nom). Le service worker prend la dernière version dès que tu es en ligne.
L'appli n'est ni un diagnostic ni un traitement.
